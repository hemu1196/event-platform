# 🎪 EventHub — College Event Registration & Ticketing Platform

> A premium, fully responsive, and highly interactive Event Registration & Ticketing Platform designed for college festivals, hackathons, seminars, and sports championships. Features a stunning dark-mode UI/UX with glassmorphism, instant branded PDF ticket generation, and seamless Supabase integration with automatic demo fallback.

---

## ✨ Features at a Glance

* 🎨 **Premium Modern UI**: Built with React, Vite, and Tailwind CSS v4, featuring glowing gradient cards, floating animated glassmorphism shapes, custom stateful buttons, and dark mesh backgrounds.
* 📦 **Dual Modes (Offline Demo & Database Sync)**:
  * **Demo Mode (Default)**: Runs fully out-of-the-box using curated offline mock data for seamless vivas/presentations without database dependencies.
  * **Supabase Database Mode**: Toggles instantly by adding keys to the `.env` file, enabling real-time event updates, registrations, and analytics.
* 🗂️ **Event Catalog & Filtering**: Interactive search bar with real-time debounced results, visual category quick-filters, and grid/list view layouts.
* 🎫 **Instant PDF Ticket Generation**: Generates highly styled, branded registration confirmations with a custom QR layout, auto-generated registration IDs (format: `REG-2026-XXXX`), and one-click PDF download using `jsPDF`.
* 🛡️ **Robust Admin Portal**:
  * Protected page `/admin` with dashboard analytics (total events, registrations, colleges involved, average fees).
  * CRUD interfaces for adding, editing, and deleting events.
  * Live participant registration tracking and logs with exportable list views.
* 🔗 **SPA Routing & Vercel Fix**: Completely optimized with `vercel.json` rewrite configurations to prevent `404 Not Found` errors on page refresh.

---

## 🛠️ Tech Stack

* **Frontend**: React 19 (Hooks, Router v7), Tailwind CSS v4, React Icons.
* **Backend/Database**: Supabase (PostgreSQL), Row Level Security (RLS) policies.
* **Document Generation**: `jsPDF` & `html2canvas` for client-side styled tickets.
* **Build Tooling**: Vite 8, ESLint.
* **Deployment**: Optimized for Vercel.

## 🚀 3-Step Setup & Deploy

### Step 1: Install & Run Locally

1. Open your terminal in the project directory and install the packages:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
   * *Note: The app will load with mock data in **Demo Mode** instantly.*

---

### Step 2: Connect Supabase Database (Optional)

1. Create a free account at [Supabase](https://supabase.com/).
2. Create a new project named **EventHub**.
3. In the Supabase Dashboard, go to **SQL Editor** > **New Query**, paste the contents of `schema.sql`, and click **Run**. This will set up:
   * `events` and `registrations` tables.
   * Proper indexing for faster searches.
   * Row-Level Security (RLS) policies for anonymous reads & inserts.
   * Premium seed data of 6 college events.
4. Copy the API credentials from **Project Settings** > **API**.
5. Create a `.env` file in the root of the project by copying `.env.example`:
   ```bash
   cp .env.example .env
   ```
6. Add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key-here
   ```
7. Restart your development server (`npm run dev`). The app will now sync with your Supabase database in real-time!

---

### Step 3: Deploy to GitHub & Vercel

#### Pushing to GitHub
1. Create a new, blank repository on [GitHub](https://github.com/new).
2. Open your terminal in the project directory and run:
   ```bash
   git add .
   git commit -m "Initial commit of EventHub Portal"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```

#### Launching on Vercel
1. Log in to [Vercel](https://vercel.com).
2. Click **Add New** > **Project** and import your GitHub repository.
3. *(Optional)* If you connected Supabase, expand the **Environment Variables** section and add:
   * `VITE_SUPABASE_URL`
   * `VITE_SUPABASE_ANON_KEY`
4. Click **Deploy**. Vercel will build the project and deliver a live, production-ready URL!
